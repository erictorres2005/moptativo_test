# Módulo Optativo — Repositorio remoto colaborativo

## 1. Descripción del proyecto

Este proyecto tiene como finalidad estudiar y demostrar el funcionamiento de un repositorio remoto mediante GitHub. Se realizará una práctica colaborativa en la que tres integrantes compartirán documentación, registrarán modificaciones y utilizarán las herramientas de control de versiones para organizar el trabajo.

## 2. Objetivos

- Comprender qué es un repositorio remoto y para qué se utiliza.
- Crear y configurar un repositorio en GitHub.
- Organizar archivos y documentación mediante una estructura clara.
- Colaborar entre varios usuarios en un mismo proyecto.
- Comprender el historial de cambios y las contribuciones de cada integrante.
- Utilizar herramientas como Issues, ramas y Pull Requests para organizar y revisar el trabajo.

## 5. Estructura del repositorio

- `documentacion/`: fundamentos y conceptos de los repositorios remotos.
- `practica/`: procedimiento de creación y utilización del repositorio.
- `evidencias/`: capturas de pantalla que demuestran el desarrollo de la práctica.
- `conclusiones/`: valoración final del grupo.

## 6. Procedimiento práctico

1. Crear el repositorio remoto en GitHub.
2. Configurar su nombre, descripción y visibilidad.
3. Añadir a los otros integrantes como colaboradores, cuando corresponda.
4. Organizar las carpetas y crear los documentos iniciales.
5. Publicar los cambios mediante GitHub Desktop o la interfaz web.
6. Comprobar el historial de cambios y las contribuciones.
7. Revisar el resultado y completar la documentación.

## 7. Colaboración y control de versiones

El grupo utilizará el repositorio remoto como espacio común de trabajo. Los cambios se registrarán mediante commits, procurando que cada uno tenga una descripción clara. Cuando resulte conveniente, se utilizarán ramas y Pull Requests para revisar las modificaciones antes de incorporarlas a la rama principal.

## 8. Seguridad y buenas prácticas

- No publicar contraseñas, tokens ni claves privadas.
- Utilizar nombres de archivos descriptivos.
- Mantener una estructura ordenada.
- Documentar los cambios importantes.
- Revisar los permisos y la visibilidad del repositorio antes de compartirlo.

## 9. Evidencias

En la carpeta `evidencias/` se incorporarán capturas de pantalla de la creación del repositorio, la incorporación de colaboradores, la publicación de cambios y el historial de versiones.

## 10. Conclusiones

El proyecto permitirá comprender cómo los repositorios remotos facilitan el almacenamiento, la organización y la colaboración en trabajos compartidos. También permitirá comprobar la utilidad del control de versiones para registrar cambios y mantener un historial del proyecto.
